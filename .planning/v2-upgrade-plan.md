## 🛠️ 技術細節

### 遷移檢查清單

```javascript
// 舊的 lightweight-charts API
const chart = createChart(container, {...})
const series = chart.addSeries(CandlestickSeries)

// 新的 KLineChart API
import { init } from 'klinecharts'
const chart = init('container-id')
chart.createShape('candle', {...})
```

### ChartManager 的改寫

你現有的 `ChartManager` 很好，但需要適配 KLineChart API：

```javascript
// 舊: 基於 lightweight-charts 的 EventEmitter
class ChartManager {
  initCharts(configs) { /* LWC API */ }
  syncCharts() { /* LWC 時間軸同步 */ }
}

// 新: 適配 KLineChart 的管理層
class ChartManager {
  initCharts(configs) { /* KLineChart API */ }
  syncCharts() { /* KLineChart 時間軸同步 */ }
  registerTools() { /* extension 工具註冊 */ }
}
```

### 數據格式兼容

```javascript
// Binance REST API 返回的格式
{
  open_time: 1234567890000,
  open: "45000.00",
  high: "46000.00",
  low: "44000.00",
  close: "45500.00",
  volume: "100.5"
}

// KLineChart 需要的格式
{
  time: 1234567890,      // 秒級時間戳
  open: 45000,           // 數字
  high: 46000,
  low: 44000,
  close: 45500,
  volume: 100.5
}

// 轉換函數 (你已有的)
const toCandle = (row) => ({
  time: Math.floor(row.open_time / 1000),
  open: parseFloat(row.open),
  high: parseFloat(row.high),
  low: parseFloat(row.low),
  close: parseFloat(row.close),
  volume: parseFloat(row.volume)
})
```
