# Plan 06-01 — Dual Chart Rendering: charts page + two stacked Lightweight Charts v5 candlestick panes (CHART-01, CHART-02, CHART-07)

## Objective

Create the charts page and render the two stacked 1h candlestick charts. Task 1 builds `public/charts.html` (stacked `#btc-chart` / `#eth-chart` panes, pinned LWC v5.2.1 standalone CDN script, a minimal reachability link from the records page, and pane CSS with explicit heights). Task 2 adds `public/js/charts.js`, which fetches one bounded 30-day window of klines for both symbols through the existing `api()` chokepoint, maps `Kline` rows to LWC v5 candle data (unix-seconds `time`), and renders a BTC candlestick series in the top pane and an ETH candlestick series in the bottom pane. Time-sync is deliberately NOT wired here — plan 06-02 adds the logical-range sync + re-entrancy guard on top of the panes this plan renders.

**Explicit non-goals (Phase 7 scope, not built here):** custom date range selection (CHART-05), record → chart deep link with 24h padding (CHART-06), log-scale toggle (CHART-04), and the shared nav bar (INFRA-06 → Phase 9). The page loads a fixed recent window on navigation only.

## Success Criteria Coverage

- **SC1** (BTC top pane + ETH bottom pane, stacked single-page) → Task 1 (`#btc-chart` above `#eth-chart`, stacked via CSS) + Task 2 (both series rendered with real D1 data).
- **SC4** (LWC v5 standalone from CDN, no build step) → Task 1 (pinned `lightweight-charts@5.2.1` standalone script tag; no npm package, no bundler) + Task 2 (v5-only API usage, verified by must-never-appear grep for the v4 `addCandlestickSeries`).
- **CHART-07** maps to SC4 above. **CHART-01** and **CHART-02** map to SC1 above.

## Dependency Graph

- Task 1 (charts.html + CSS + reachability link, deploy) → Task 2 (charts.js fetch + render, deploy, browser checkpoint). Plan 06-02 (sync) depends on this plan's Task 2 output (the two chart instances / time scales). Plan 06-01 depends on 05-02 only because prior plans edited `public/index.html` and `public/js/*` last — sequential execution avoids file conflicts. Acyclic.

    Create public/js/charts.js — an ES module (matches records.js style: imports, DOM reads, networking via api()):
    ```
    import { api } from './api.js';

    const DEFAULT_WINDOW_SECONDS = 30 * 24 * 3600;

    function toCandle(row) {
      return {
        time: row.open_time,
        open: row.open,
        high: row.high,
        low: row.low,
        close: row.close,
      };
    }

    async function loadWindow(symbol) {
      const endMs = Date.now();
      const startMs = endMs - DEFAULT_WINDOW_SECONDS * 1000;
      return api(`/api/klines?symbol=${encodeURIComponent(symbol)}&start=${startMs}&end=${endMs}`);
    }

    function renderChart(containerId, candles) {
      const chart = LightweightCharts.createChart(document.getElementById(containerId), {
        height: 420,
        layout: {
          background: { type: 'solid', color: '#ffffff' },
          textColor: '#1f2328',
        },
        timeScale: { borderColor: '#d0d7de', rightOffset: 5 },
        rightPriceScale: { borderColor: '#d0d7de' },
      });
      const series = chart.addSeries(LightweightCharts.CandlestickSeries, {
        upColor: '#26a69a',
        downColor: '#ef5350',
        borderVisible: false,
        wickUpColor: '#26a69a',
        wickDownColor: '#ef5350',
      });
      series.setData(candles);
      return { chart, series };
    }

    async function init() {
      const errorEl = document.getElementById('chart-error');
      try {
        const [btcRows, ethRows] = await Promise.all([loadWindow('BTCUSDT'), loadWindow('ETHUSDT')]);
        renderChart('btc-chart', btcRows.map(toCandle));
        renderChart('eth-chart', ethRows.map(toCandle));
      } catch (error) {
        errorEl.textContent = `載入 K 線失敗：${error.message}`;
        errorEl.hidden = false;
      }
    }

    init();
    ```
    Key points:
    - `/api/klines` contract (Phase 1 route): `start`/`end` are millisecond timestamps; the route converts to seconds server-side. charts.js passes `Date.now()` ms and `endMs - 30*24*3600*1000` ms. The window is bounded (~720 candles/symbol) — this is a load-once-per-navigation fetch, NOT a per-scroll fetch (PITFALLS.md performance trap: fetching the whole dataset on every pan/zoom is the anti-pattern).
    - `toCandle()` maps `Kline` fields 1:1; `open_time` is already unix seconds, which is exactly LWC v5's `UTCTimestamp` time format. No conversion, no rounding, no timezone math.
    - v5 API ONLY: `LightweightCharts.createChart(...)` + `chart.addSeries(LightweightCharts.CandlestickSeries, ...)` + `series.setData(...)`. The v4 `addCandlestickSeries()` does not exist in v5 and must not be used.
    - All networking through `api()` (no direct `fetch()`), same chokepoint discipline as records.js.
    - Error rendering uses `textContent`, never `innerHTML` (XSS discipline from Phase 4). A failed CDN load also surfaces here because `LightweightCharts` is undefined → createChart throws → caught.
    - Time-sync is intentionally not wired in this plan (06-02 adds it). The return value of renderChart currently flows nowhere; 06-02 will refactor init() to keep the chart references and wire the sync.

    Deploy with `npx wrangler deploy`.
