# Plan 01-02 — D1 Schema, JSON Envelope API Skeleton, Zod Validation

## Objective

Make the D1 schema live (per the phase goal), stand up the Hono API skeleton where every route returns the `{ok, data|error}` envelope (INFRA-02), and reject invalid POST/PUT bodies with a Zod validation error before the database is touched (INFRA-03 / SC3).

## Success Criteria Coverage

- **SC2** (any API route returns `{ok, data|error}`) → Task 2.
- **SC3** (invalid POST/PUT rejected with Zod error before touching DB) → Task 3.
- **INFRA-02** (Hono router + JSON envelope) → Task 2.
- **INFRA-03** (Zod validation at the Worker boundary) → Task 3.
- **Phase goal "D1 schema is live"** → Task 1 (migrations for `klines` and `divergence_records`, applied local + remote).

## Dependency Graph

- Task 1 (DB + migrations) → Task 2 (envelope API skeleton, reads the DB) → Task 3 (Zod validation on writes). Builds on plan 01-01's scaffold and deployed Worker.
