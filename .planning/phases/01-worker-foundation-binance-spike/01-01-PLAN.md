# Plan 01-01 — Worker Scaffold, Static Assets Binding, Git Hygiene

## Objective

Stand up the single Cloudflare Worker project (per the locked decision to consolidate to Workers + Static Assets, not Pages + a separate Workers project), prove it deploys and serves a static asset bundle through the `assets` binding, and guarantee `.dev.vars` / `.wrangler/` can never leak into git.

## Success Criteria Coverage

- **SC1** (deployed URL serves static assets via the binding, no Pages project) → Task 2.
- **SC4** (`.dev.vars` and `.wrangler/` absent from git tracking) → Task 3.
- **INFRA-01** (single Worker + Static Assets binding) → Tasks 1 & 2.
- **INFRA-05** (`.dev.vars` / `.wrangler/` in `.gitignore`) → Task 3.

## Dependency Graph

- Task 1 (scaffold) → Task 2 (assets + deploy) → Task 3 (git hygiene). All in-file, sequential; nothing from another plan is consumed yet.

<task type="auto">
  <name>Initialize the Worker project scaffold with assets binding</name>
  <files>package.json, package-lock.json, tsconfig.json, wrangler.jsonc, src/index.ts, .gitignore</files>
  <action>
    Run `npm init -y`, then set package.json: `"private": true`, `"type": "module"`, and scripts `"dev": "wrangler dev"`, `"deploy": "wrangler deploy"`, `"typecheck": "tsc --noEmit"`.
    Install runtime deps `npm install hono zod` and dev deps `npm install -D wrangler typescript @cloudflare/workers-types vitest @cloudflare/vitest-pool-workers`.
    Write tsconfig.json with `target: "ES2022"`, `module: "ESNext"`, `moduleResolution: "Bundler"`, `strict: true`, `noEmit: true`, `types: ["@cloudflare/workers-types"]`, `lib: ["ES2022", "WebWorker"]`.
    Write wrangler.jsonc — the SINGLE deployable for this project (no Pages):
    `{ "name": "btcethdivergence", "main": "src/index.ts", "compatibility_date": "2026-08-30", "assets": { "directory": "./public", "binding": "ASSETS" } }`.
    Do NOT add a D1 binding yet — that lands in plan 01-02 with the database creation, so the first deploy has no dangling binding.
    Write src/index.ts as a minimal fetch handler: export `fetch(request)` returning `new Response("ok", { status: 200 })` for any non-`/api` path (the Hono router replaces this in 01-02).
    Write a first-pass .gitignore covering `node_modules/`, `dist/`, `*.local`, `.env`, `.env.*`, `.dev.vars`, `.wrangler/` (Task 3 hardens it with verify commands).
  </action>
  <verify>
    `npm run typecheck` exits 0.
    `npx wrangler deploy --dry-run --outdir dist` exits 0 (bundle builds against the assets binding).
    `npm ls hono zod` shows both installed.
  </verify>
  <done>Project builds and dry-run-deploys; wrangler.jsonc declares the assets binding over ./public as the only static-asset mechanism.</done>
</task>
